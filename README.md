# عفاف حضرموت نت — النسخة الجديدة

تتضمن:
- تسجيل ودخول وتأكيد البريد.
- عدم فتح «أكمل بياناتك» تلقائيًا بعد تسجيل الدخول؛ يفتح المستخدم «ملفي» بنفسه.
- تعديل الملف والتفضيلات.
- فصل البحث تلقائيًا: الشاب يرى البنات فقط والبنت ترى الشباب فقط.
- طلب تواصل رسمي وطلب خاص يمران على المشرف.
- مراسلة خاصة بعد الموافقة.
- إبلاغ عن المستخدم أو رسالة.
- حظر المستخدم.
- الإبلاغ عن عطل داخل الموقع وتحويله إلى لوحة المشرف.
- ثلاثة أدوار مشرفين: رئيسي، ثانٍ، وثالث محدود، لكل حساب مستقل.
- سجل إجراءات يوضح المشرف الذي راجع أو حذف أو حظر أو عدّل حالة.
- لوحة المشرف لإدارة الطلبات والبلاغات والأعطال والمستخدمين والرسائل.

## مهم قبل التشغيل
1. ارفع الملفات الأربعة إلى المستودع بأسمائها: `index.html`, `search.html`, `chat.html`, `admin.html`.
2. نفّذ `supabase_migration_v3.sql` في Supabase SQL Editor.
3. بعد إنشاء حسابك وتسجيل ملفك، عيّن حسابك مشرفًا رئيسيًا عبر السطر الموجود في آخر ملف SQL بعد وضع UUID لحسابك.
4. أنشئ حسابي المشرف الثاني والثالث بشكل مستقل، ثم عيّن لهما الصلاحيات من لوحة المشرف الرئيسي.
